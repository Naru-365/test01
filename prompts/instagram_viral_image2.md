# Instagramでバズりやすい image2 用プロンプト集

以下はそのまま使えるテンプレです。`{}`の部分だけ差し替えてください。

---

## 1) 一発で目を引く「対比」型

```
Create an Instagram vertical key visual (1080x1920) featuring a dramatic contrast between {A} and {B}. 
Cinematic lighting, ultra-detailed textures, one clear focal subject, high color contrast, clean negative space for caption overlay.
Style: modern editorial + surreal realism.
Emotion: surprise + aspiration.
No watermark, no logo, no extra text.
```

## 2) 保存されやすい「実用」型

```
Generate a visually striking Instagram story/post image (9:16) about {topic}.
Design should feel premium, minimal, and instantly understandable in under 1 second.
Use icon-like symbolic objects, layered depth, soft glow, and bold central composition.
Color palette: {palette}.
Mood: smart, useful, highly saveable.
No readable text embedded in image.
```

## 3) コメントが増える「二択」型

```
Create a split-scene Instagram vertical artwork (1080x1920) showing two compelling options: {option1} vs {option2}.
Balanced composition, strong visual hierarchy, eye-tracking leading lines, viral social-media aesthetic.
High dynamic range, polished details, premium look.
No letters, no numbers, no logos.
```

## 4) リールのサムネ向け「強フック」型

```
Create a thumbnail-style vertical image for Instagram Reels.
Subject: {subject}.
Hook feeling: "I need to know more right now".
Use extreme foreground-background depth, dramatic perspective, and bold lighting.
Keep one dominant subject, avoid clutter.
No text overlay in image.
```
